# Pirut

Pirut is currently in project preparation. It does not contain an application, a runnable development environment, a database schema, Docker definitions, or release automation yet.

The intended product is a private-first Hebrew web application for manually importing and analyzing Israeli credit card statements.

See [the living project foundation plan](docs/project-foundation.md) for approved decisions, planned work, blockers, and the handoff to the separate foundation implementation task.
